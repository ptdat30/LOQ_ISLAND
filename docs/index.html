Hướng Dẫn Deploy Trang Wiki (30 Giây)

Trang wiki này được đóng gói độc lập trong thư mục /docs, sẵn sàng online miễn phí vĩnh viễn.

Cách 1: Kích hoạt GitHub Pages (Khuyên dùng - Không cần cài đặt gì)
  1. Đẩy code lên GitHub repository của bạn: git push origin main.
  2. Trên trình duyệt, vào trang repository GitHub của bạn > Nhấn vào tab Settings.
  3. Tại menu bên trái, chọn mục Pages.
  4. Trong phần Build and deployment:
    • Source: Chọn Deploy from a branch.
    • Branch: Chọn main và chọn thư mục /docs.
  5. Nhấn Save. Chờ 30 giây, link trang web wiki của bạn sẽ hiện ra:
    https://<your-username>.github.io/<repository-name>/
Cách 2: Deploy qua Vercel hoặc Netlify

Truy cập Vercel hoặc Netlify > Import repo của bạn > Chọn Root Directory là docs > Nhấn Deploy. Bạn sẽ có domain miễn phí ngay tức thì.

Cách 3: Mở trực tiếp trên máy tính (Offline 100%)

Mở thư mục docs/ trong máy và nhấp đúp chuột vào file index.html để xem trực tiếp trên mọi trình duyệt (Chrome, Edge, Firefox) mà không cần cài đặt Node.js hay bật server!
