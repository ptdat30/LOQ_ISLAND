Cách Deploy Trang Wiki (10 Giây)

Bật GitHub Pages Miễn Phí Vĩnh Viễn:
  1. Truy cập vào trang GitHub repo của bạn: LOQ_ISLAND > Bấm vào Settings.
  2. Tại cột menu bên trái, nhấn vào Pages.
  3. Mục Build and deployment:
    • Source: Deploy from a branch
    • Branch: main và chọn thư mục /docs
  4. (Lưu ý quan trọng): Ô Custom domain hãy để trống hoàn toàn!
  5. Bấm Save. Sau 30 giây, link trang web 3D của bạn sẽ tự động chạy:
    https://<username>.github.io/LOQ_ISLAND/
