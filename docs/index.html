Triển Khai Trang Web (Deploy 10s)

Trang bảo tàng này nằm trọn trong thư mục docs/.

Kích Hoạt GitHub Pages Miễn Phí:

  1. Vào GitHub repo LOQ_ISLAND > Nhấp vào Settings.
  2. Tại menu trái, chọn Pages.
  3. Phần Build and deployment:
    • Source: Deploy from a branch
    • Branch: chọn main và thư mục /docs
  4. Bấm Save. Chờ 30 giây để trang web hiển thị tại:
    https://<username>.github.io/LOQ_ISLAND/
